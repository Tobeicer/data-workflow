# 京东来源适配器

状态：目录契约已建立，采集实现尚未开始。

## 用途

补充品牌、型号、参数、价格和同款候选，不作为高可信主数据的直接覆盖来源。

## 采集边界

本适配器采集平台可访问的商品信息；为完成采集，允许采取降低或解除来源风控影响的技术手段（拟人化、指纹伪装、代理/IP 轮换、自动处理验证码或滑块、跟随接口签名等），采集策略以总纲第 2 节为准。

## 停止条件

遇到登录要求、验证码、滑块、403/429、权限或签名限制、来源条款不明确、页面结构变化或异常请求量时，先按采集策略自动处理或降频，仍失败则停止当前路径，记录具体状态并保留证据，按状态契约路由（重试/人工/降频）。

## 晋级标准

完成小样本验证、脱敏 fixtures、解析与契约测试、统一 CLI 和 `--dry-run`、L0-L2、变化检测、质量门禁与 `run_result.json` 后才能从 `planned` 晋级；连续稳定运行验收前不得启用 n8n。
