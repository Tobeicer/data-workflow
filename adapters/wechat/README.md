# 微信来源适配器（实验性）

状态：`planning`——2026-08-06 确认采用 WeLive 作为采集引擎，H1 证据任务未开始；未进入任何生产链路。
唯一现行总纲：`../../docs/游艺圈数据工作流总纲.md`（Phase H）

## 来源定位与范围

- 来源：个人微信（非企业），自有账号。
- 采集对象：群聊消息、朋友圈本地缓存、部分个人聊天对话（按白名单）。
- 定位：实验性社交信息来源，用于业务所需的授权/内测群聊与朋友圈信息分析；不参与七个商品来源的采集与启用流程（G4）。

## 工具决策（2026-08-06 确认）

- 采集引擎：**WeLive**（本地微信数据库解密与监听工具）。
  - 实时机制：`monitor sse` 流式推送新消息与数据库变更事件（秒级准实时）。
  - 导出：JSONL / Markdown；私聊/群聊/公众号分类过滤、时间范围与关键词筛选。
  - 朋友圈：快照增量导入；本地缓存素材解密。
  - 自动化：CLI + HTTP + Web 控制台，可被 n8n/Python 直接驱动。
- 兜底：PyWxDump（全版本密钥提取与解密导出），用于 WeLive 因微信版本升级失效时的全量导出。
- 前提：微信 PC 4.0.x 保持登录运行；**锁定版本、关闭自动更新**；升级前等待社区补丁。

## 数据链路与目录

```text
微信 PC 4.0.x（Windows，常驻登录）
   ↓ 本地库变化
WeLive（monitor sse / 导出）
   ↓
adapters/wechat/src/collector.py → L0 原始 JSONL
   ↓ 清洗、分类、去重
PostgreSQL staging：wechat_msg / wechat_moment / wechat_contact / sync_watermark
```

- 增量同步：水位表记录最后同步位置；消息以 msgId 为幂等键去重；朋友圈按时间快照增量比对。
- 范围控制：`config/scope.json` 白名单（群/联系人/朋友圈作者），白名单外一律不采。
- 管道与工具解耦：WeLive 只产 L0 原始资产，清洗/入库/分析全部为自有代码，工具失效可替换。

## 边界与停止条件

- 仅采集自有账号可见数据；群聊、朋友圈含第三方个人数据，不得对外发布、不得用于商业画像、不得进入正式业务生产管线。
- 微信升级导致解密失效、工具仓库被 DMCA 删除、出现白名单外数据请求时，停止对应路径并记录状态。
- 正式合规路径（企业微信会话存档/客户朋友圈官方 API）不受本实验链路影响。

## 风险

- 灰色工具（本地解密）受微信服务条款与 DMCA 影响，生命周期不可控。
- "实时"为本地库监听准实时，非推送式；朋友圈仅覆盖本地已缓存部分。
- 数据仅限个人自用与授权场景；涉及第三方数据时注意个人信息保护要求。
